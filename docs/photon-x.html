Photon X

Photon X — это встроенный CSS-движок нового поколения. Вы пишете стили прямо в HTML через классы с префиксом _, а движок сам генерирует CSS и вставляет его в <head>. Никаких дополнительных CSS-файлов — вся стилизация через классы.

Достаточно подключить photon-kit-x.js и использовать классы вида _bg--6c5ce7, _flex-center, _hover:bg--ff7675.

<div class="_bg--f8f9fa _flex-center _p--2rem _minh--100vh">
  <h1 class="_c--333 _fs--2rem">Привет, Photon X!</h1>
</div>

Подключение

Просто добавьте скрипт перед закрывающим </body>:

<script src="https://photon.p7z.ru/js/photon-kit-x.js"></script>

Движок автоматически просканирует все элементы с классами _* при загрузке страницы и при динамических изменениях (через MutationObserver).
