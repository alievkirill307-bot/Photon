Таймер для акций

Обратный отсчёт до указанной даты. Идеально подходит для акций, распродаж, запусков и любых событий с ограничением по времени. Работает на чистом JavaScript без внешних зависимостей.

Демо

Таймер автоматически обновляется каждую секунду. В демо ниже используется автообновление на 120 дней — дата сбрасывается при истечении.

JavaScript-код

Вставьте этот скрипт перед закрывающим тегом </body>. Укажите свою дату в переменной TARGET_DATE — таймер будет отсчитывать время до неё. Если нужно автообновление, раскомментируйте альтернативный вариант.

Фиксированная дата (основной): "YYYY-MM-DDTHH:MM:SS" (например, "2027-01-01T00:00:00").
Автообновление (альтернатива): переменная DAYS_AUTO — таймер сам переустанавливается на указанное количество дней после истечения. 
<script>
  (function () {
    'use strict';

    /* ========================================
       ОСНОВНОЙ ВАРИАНТ — ФИКСИРОВАННАЯ ДАТА
       Укажите свою дату в TARGET_DATE:
       ======================================== */
    var TARGET_DATE = '2027-01-01T00:00:00';
    var target = new Date(TARGET_DATE).getTime();

    /* ========================================
       АЛЬТЕРНАТИВА — АВТООБНОВЛЕНИЕ НА 120 ДНЕЙ
       Раскомментируйте, если нужно автообновление:
       ======================================== */
    // var DAYS_AUTO = 120;
    // var target = new Date().getTime() + DAYS_AUTO * 24 * 60 * 60 * 1000;

    function pad(n) {
      return n < 10 ? '0' + n : '' + n;
    }

    function update() {
      var now = new Date().getTime();

      if (target <= now) {
        target = now + DAYS_AUTO * 24 * 60 * 60 * 1000;
      }

      var diff = target - now;

      var daysEl = document.getElementById('countdown-days');
      var hoursEl = document.getElementById('countdown-hours');
      var minutesEl = document.getElementById('countdown-minutes');
      var secondsEl = document.getElementById('countdown-seconds');

      var days = Math.floor(diff / (1000 * 60 * 60 * 24));
      var hours = Math.floor((diff % (1000 * 60 * 60 * 24)) / (1000 * 60 * 60));
      var minutes = Math.floor((diff % (1000 * 60 * 60)) / (1000 * 60));
      var seconds = Math.floor((diff % (1000 * 60)) / 1000);

      if (daysEl) daysEl.textContent = pad(days);
      if (hoursEl) hoursEl.textContent = pad(hours);
      if (minutesEl) minutesEl.textContent = pad(minutes);
      if (secondsEl) secondsEl.textContent = pad(seconds);
    }

    update();
    setInterval(update, 1000);
  })();
</script>

Настройка

Переменная / ЭлементНазначение
TARGET_DATEОсновной вариант. Фиксированная дата окончания таймера в формате "YYYY-MM-DDTHH:MM:SS"
DAYS_AUTOАльтернатива. Количество дней для автообновления (по умолчанию 120). При истечении таймер сам переустанавливается на сейчас + DAYS_AUTO
#countdown-daysЭлемент для отображения дней
#countdown-hoursЭлемент для отображения часов
#countdown-minutesЭлемент для отображения минут
#countdown-secondsЭлемент для отображения секунд
